# Bite Rush Kiosk

A desktop-based self-service kiosk system developed using VB.NET.

## Features

- Food and menu ordering
- Cash payment
- Cashless payment
- Transaction confirmation through an on-screen MessageBox
- Desktop-based kiosk interface

## Technologies Used

- VB.NET
- Visual Studio

## Project Type

Desktop Application

## Project Year

2022
